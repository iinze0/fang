FANG

Modular Kali toolkit. Private repo: clone, run, then update with git.

Install

git clone git@github.com:iinze0/fang.git
cd fang
chmod +x fang.sh update.sh lib/*.sh
sudo ./fang.sh

Update

cd fang
./update.sh

Or:

cd fang
git pull origin main
chmod +x fang.sh update.sh lib/*.sh

Must be a git clone. A copied folder cannot pull updates.
