fang

Modular Kali network toolkit · iinze0 · MIT

Install

git clone https://github.com/iinze0/fang.git
cd fang
chmod +x fang.sh update.sh lib/*.sh
sudo ./fang.sh

Update

cd fang
./update.sh

Must be a git clone. A copied folder cannot pull updates.

Authorized lab use only.
